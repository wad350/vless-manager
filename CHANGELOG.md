# Changelog

## v1.18.2

- Удалены отдельная фоновая проверка WAN и её таймеры. Статус интерфейса использует те же результаты, что и автоматика включения/отключения VPN; ручная проверка остаётся доступна и не меняет решение автоматики.
- Адрес проверки серверов подписки и контроля активного VPN объединён в «Адрес проверки через VPN». Пользовательский адрес сохраняется при обновлении; старый `failover_health_url` мигрирует в общий `ping_test_url`, а старое имя поля принимается API для совместимости. Если оба адреса были изменены, приоритет имеет адрес проверки серверов.
- Настройки первой загрузки и таймаута подписки, адреса и таймаута теста серверов, параллельности и ожидания временного Xray перенесены в **Настройки → Подписки**. Прямые проверки оператора остаются отдельными и выполняются мимо VPN.
- Исправлена потеря первого нажатия на другой раздел настроек после редактирования поля. Изменения сохраняются в черновике при переходах между разделами.
- Добавлены проверки миграции настроек, общего VPN-адреса, единого WAN-статуса и сериализации ручных/автоматических проверок. Xray v26.10.21+manager.26, TPROXY и MIPS-криптография не изменены.

Известные ограничения мобильного подключения под полной нагрузкой (задержки DNS и отдельные сетевые таймауты) остаются; этот выпуск не объявляет их устранёнными.

## v1.18.1

- Встроенный Xray обновлён до v26.10.21 (upstream pre-release), включая исправления TLS/RootCAs, совместимость XTLS Vision с Go 1.27.3, REALITY и отмену/закрытие соединений Hysteria. Сохранены локальные исправления TPROXY, UDP, счётчиков и изоляции экземпляров. Экспериментальные gRPC-пул и прямой декодер в выпуск не включены.
- Закрытие временного SOCKS UDP-соединения защищено от повторного вызова таймером и конкурентного закрытия; добавлен race-тест.
- Ускорен Poly1305 на MIPS32r2: новый ассемблерный backend MACC использует накопление произведений инструкциями MADDU. Алгоритм, формат тегов и проверки аутентификации не изменены.
- MACC включается по умолчанию только на проверенной топологии MT7621 (два физических ядра, четыре VPE). Прежний ASM и штатный Go-backend остаются доступны через переменные окружения; ARM64 и остальные MIPS не меняют свои настройки.
- Расширены нативные проверки Poly1305 и AEAD: случайные состояния, переносы, невыровненные данные, границы страниц, потоковая обработка и конкурентное выполнение с GC. Добавлена проверка кодирования инструкций MACC и выбора backend.
- Сборка и CI переведены на Go 1.27.3 с исправлением проверки недоверенных промежуточных сертификатов в `crypto/x509` ([GO-2026-6809](https://pkg.go.dev/vuln/GO-2026-6809)).

### Известное ограничение

На мобильном подключении при полной загрузке туннеля возможны задержки DNS и отдельные таймауты. Этот выпуск не объявляет их устранёнными и не увеличивает системные таймауты.

## v1.18.0

- Страница обновления показывает changelog из GitHub для всех промежуточных версий и полную историю релизов.
- Выбор самого быстрого сервера использует один проход без повторной сортировки; свежая проверка не читает ping-кеш.
- MIPS-сборка повторно использует проверенный staging криптомодуля с ключом по содержимому исходников, генератора и overlay.
- Удалены неиспользуемые функции, старые артефакты sing-box и эксперименты TUN/UDP; тестовые helpers перенесены в `_test.go`.
- Исправлены выявленные ошибки владения буферами, закрытия ресурсов, конфигурации и конкурентного доступа в менеджере и Xray.
- Документация сокращена; штатный UDP batching через `recvmmsg` сохранён.
