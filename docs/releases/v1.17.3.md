# VLESS Manager 1.17.3

## Changes

- Update embedded Xray to the pinned v26.10.10 prerelease, with the manager's
  native TPROXY, gRPC buffer/lifecycle, instance isolation and traffic-accounting
  patches preserved. This is a locally patched build, not the official binary.
- Enable bounded MIPS32r2 Poly1305 assembly by default on the tested MT7621
  two-core/four-VPE profile. Fresh Go 1.27.2 native AEAD comparisons measured
  24-62% higher median throughput with the same accelerated ChaCha20. This is a crypto benchmark,
  not a promise of equivalent VPN or modem throughput.
- Preserve upstream authentication tags, tails, finalization and verification.
  Other router profiles keep their previous defaults. Set
  `VLESS_MANAGER_MIPS_POLY1305=generic` to disable only the new backend;
  `VLESS_MANAGER_MIPS_CHACHA20=generic` disables both assembly backends.
- Gate upstream MASQUE configuration behind `xray_masque`, like optional TUN
  and WireGuard, to keep the standard manager free of gVisor.
- Add session-revocation tests and validate both built IPK architectures before
  publishing release assets.
- Build with Go 1.27.2 and update `golang.org/x/net` to 0.60.0 and
  `github.com/klauspost/compress` to 1.18.7 for their published security fixes.

## Verification

- Full manager and Xray race tests, focused transport tests, native MIPS crypto
  and UDP batching tests, installer tests, and MIPSLE/ARM64 package builds.
- Native crypto checks include RFC vectors, invalid tags, independent Go
  comparisons, unaligned/protected-page buffers, concurrent GC, and 100,000
  chained authentication comparisons per run.
- Live MT7621: VPN TCP/UDP, domain bypass, local access, health monitoring,
  subscription refresh, and traffic accounting. The bypass base remains the
  original 910-domain list, without continual candidate validation.
- Mac Hysteria2 chain through a fixed-destination temporary router relay and
  VLESS: 120/120 requests passed, with packet capture proving no direct WAN
  exit for that flow. The temporary relay is not a product feature.
- Cloudflare tunnel speedtest completed at 17.72/15.80 Mbps in the recorded
  pre-release check. Results depend on the mobile network and VPN server.

## Limitations

- Speedtest.ru still intermittently encounters TLS handshake timeouts. This
  release does not claim to fix those network failures.
- Capture policy covers IPv4 TCP/UDP. VLESS does not carry ICMP or arbitrary
  IP protocols; IPv6 interception is not implemented.
- ARM64 is build/test validated, not live-tested on ARM64 hardware in this run.
- The manager passes `go vet`. The full upstream Xray tree retains static
  diagnostics concerning private TLS-field access, protobuf lock copies,
  unreachable code and test helpers; a clean full-tree vet result is not claimed.
- These checks are not a formal cryptographic audit. The optional upstream
  10-billion-iteration Poly1305 burn-in was not run; the bounded chained test
  compares each intermediate tag to the upstream Go implementation.
